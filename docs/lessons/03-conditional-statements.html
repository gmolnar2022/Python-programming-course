Conditional Statements in Python

Learning objectives

After completing this lesson, you should be able to:

  • create logical expressions that evaluate to True or False;
  • use the logical operators not, and, and or;
  • compare values using comparison operators;
  • distinguish between comparison and assignment operators;
  • apply compound assignment operators;
  • understand the basic precedence of arithmetic, comparison, and logical operators;
  • implement binary and unary selection using if, else, and elif;
  • use nested and chained conditionals;
  • implement multi-way selection using match–case;
  • use a conditional expression for simple binary selection.

Logical expressions

A logical expression is an expression that evaluates to a Boolean value: either True or False.

For example:

x = 4

print(x == 4)
print(x > 3)
print(x < 5)

Output:

True
True
True

Logical expressions are particularly important when a program has to make a decision. A condition in an if statement is a logical expression.

Logical operators

Logical operators operate on Boolean expressions and combine their results into a single Boolean value.

Python provides three basic logical operators:

  • not – True if its operand is False, and False if its operand is True;
  • and – True if and only if both operands are True;
  • or – True if at least one operand is True.

Truth table

X Y X and Y X or Y not X not Y
True True True True False False
True False False True False True
False True False True True False
False False False False True True

Examples:

x = 10
y = 8

print(x == 10 and y == 8)
print(x == 10 or y == 20)
print(not (x == 10))

Output:

True
True
False

Logical operators can also be combined:

a = True
b = False
c = False

r = (a and b) and (b or c)
print(r)

Comparison operators

Comparison operators compare two values or expressions. The result of a comparison is a Boolean value.

Operator Description Example
< Less than x < 5
> Greater than y > 3
<= Less than or equal to x + 5 <= y
>= Greater than or equal to y >= x - 2
== Equal to x == 3
!= Not equal to x != y

For example:

x = 5

print(x > 3)
print(x == 5)
print(x != 5)
ImportantAssignment or comparison?

Do not confuse the assignment operator = with the equality comparison operator ==.

x = 5       # assign the value 5 to x
x == 5      # compare x with 5

The first statement changes the value associated with x. The second expression evaluates to True or False.

Assignment operators

Assignment operators are used to assign values to variables. Python also provides compound assignment operators, which combine an arithmetic operation with assignment.

Operator Example Meaning
= x = 10 assign 10 to x
+= x += 10 x = x + 10
-= y -= 5 y = y - 5
*= z *= 2 z = z * 2
/= a /= 3 a = a / 3
%= b %= 5 b = b % 5
//= c //= 5 c = c // 5

For example:

x = 10
x += 5
print(x)

Output:

15

Precedence of operators

When an expression contains several operators, operator precedence determines which operation is evaluated first.

The following simplified precedence table contains the operators used in this course so far, from higher to lower precedence:

Precedence Operators
1 (), []
2 **
3 unary +, unary -
4 *, /, //, %
5 +, -
6 <, >, ==, !=, <=, >=
7 not
8 and
9 or

For example:

x = 5
result = x > 3 and x < 10
print(result)

The comparisons are evaluated before the and operator.

TipUse parentheses for clarity

Even when you know the precedence rules, parentheses can make a complex logical expression easier to read:

result = (x > 3) and (x < 10)

Selection

So far, our programs have mainly executed instructions one after another. This is called sequence.

Selection allows a program to choose between different paths depending on a condition. The condition is a logical expression that evaluates to either True or False.

Binary selection: if–else

Binary selection means that the program can follow one of two possible paths depending on a condition.

The general form is:

if condition:
    commands
else:
    other_commands

For example:

x = int(input("Give me a whole number other than zero: "))

if x > 0:
    print(f"{x} is positive")
else:
    print(f"{x} is negative")

Another example can be used to prevent an invalid division:

a = 10
b = int(input("Enter a whole number: "))

if b == 0:
    print("The division cannot be performed")
else:
    print(f"The quotient of {a} and {b}: {a / b}")
ImportantIndentation matters

Python uses indentation to determine which statements belong to a branch.

if x > 0:
    print("Positive")
    print("This line also belongs to the if branch")

Statements at the same indentation level belong to the same block.

Unary selection: if

Sometimes an action is required only when a condition is true. In this case, an else branch is not necessary.

This is unary selection:

if condition:
    commands

For example:

x = int(input("Give me a whole number other than zero: "))

if x % 5 == 0:
    print(f"{x} can be divided by 5")

If the condition is False, the indented statement is simply skipped and execution continues after the if statement.

A unary selection can also be used when additional information is needed only in a particular case:

first_name = input("First name: ")
last_name = input("Last name: ")
answer = input("Do you have a middle name? (yes/no): ")

if answer == "yes":
    middle_name = input("Middle name: ")
    print(f"Hello {first_name} {middle_name} {last_name}")

Nested conditionals

A conditional statement can be placed inside another conditional statement. This is called a nested conditional.

General form:

if condition:
    commands
else:
    if condition2:
        commands2
    else:
        other_commands

For example, we can distinguish between positive, zero, and negative numbers:

x = int(input("Enter a whole number: "))

if x > 0:
    print(f"{x} is positive")
else:
    if x == 0:
        print(f"{x} is zero")
    else:
        print(f"{x} is negative")

The second if statement is evaluated only when the first condition is false.

Chained conditionals: elif

When several mutually exclusive conditions have to be checked, nested if statements can often be written more clearly using elif.

elif combines else and if:

if condition:
    commands
elif condition2:
    commands2
else:
    other_commands

The previous example can therefore be written as:

x = int(input("Enter a whole number: "))

if x > 0:
    print(f"{x} is positive")
elif x == 0:
    print(f"{x} is zero")
else:
    print(f"{x} is negative")

More than one elif branch can be used:

if condition1:
    commands1
elif condition2:
    commands2
elif condition3:
    commands3
else:
    other_commands

Python checks the conditions from top to bottom. Once a true condition is found, its branch is executed and the remaining branches are skipped.

match–case statement

Starting from Python 3.10, the match–case statement can be used to implement multi-way selection.

Its general structure is:

match parameter_value:
    case value1:
        commands1
    case value2:
        commands2
    case value3:
        commands3
    case _:
        other_commands

The special pattern _ acts as the default case.

For example:

grade = int(input("Enter your grade: "))

match grade:
    case 1:
        print("Failed")
    case 2:
        print("Sufficient")
    case 3:
        print("Average")
    case 4:
        print("Good")
    case 5:
        print("Excellent")
    case _:
        print("You entered a wrong number")
NoteWhen is match–case useful?

match–case can make code easier to read when one value is compared with several possible alternatives. The same type of problem can often also be solved with an if–elif–else chain.

Conditional expressions

For a very simple binary selection, Python provides a conditional expression, sometimes called the ternary operator.

Its form is:

result_if_true if condition else result_if_false

For example:

x = 5
print("Even" if x % 2 == 0 else "Odd")

Output:

Odd
TipKeep it simple

Conditional expressions are useful for short, simple decisions. For more complex logic, a normal if–else statement is usually easier to read.

Summary

In this lesson, we introduced the selection control structure. A program can make decisions by evaluating logical expressions and executing different statements depending on their Boolean result.

The main Python constructs introduced were:

  • logical operators: not, and, or;
  • comparison operators such as <, >, ==, and !=;
  • binary selection with if–else;
  • unary selection with if;
  • nested conditionals;
  • chained conditionals with elif;
  • multi-way selection with match–case;
  • conditional expressions for simple two-way decisions.
