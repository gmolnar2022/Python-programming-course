Enter your 6-character Neptun code before starting the exercises.
Programming rules: use functions and procedures with structured loops and conditions. Use lambda, map() and filter() only when explicitly requested: here, only in Exercise 5. Otherwise use structured algorithmic elements. Comprehensions, generators, break, continue and built-in algorithm shortcuts are not permitted. Return values from functions normally, but do not use return to escape a loop. Type annotations are optional. Use random only in Exercise 4; math is optional in Exercise 1. Meaningful input prompts and output labels are welcome. All inputs may be assumed valid. Suggested task time: 160 minutes, leaving 20 minutes for discussion and checking within the 180-minute class.
Working model: only one exercise can be active at a time. Press Start/Continue to open its editor and start its active-time clock. Press Stop to pause and save it. Code and progress are stored in this browser.
